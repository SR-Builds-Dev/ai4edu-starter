# AI4EDU Starter

A minimal React, Vite, Tailwind, and ESLint starter for an AI-in-Education hackathon.

## Start locally

```bash
npm install
npm run dev
```

## Before your demo

1. Replace the homepage story and example cards in `src/App.jsx`.
2. Add your AI/backend call where the `startDemo` function is today.
3. Put non-secret browser configuration in `.env` using `VITE_` names. Never expose private API keys in the frontend.
4. Run `npm run lint` and `npm run build`.

## Deploy

Push this folder to a new GitHub repository, import it in Vercel, and use the defaults: `npm run build`, output `dist`.
